# Design System Style

Use a Soft Minimal System style.

Visual direction:
- ultra clean light theme
- soft neutral grayscale palette
- subtle borders instead of heavy shadows
- large whitespace
- typography-driven hierarchy
- calm enterprise aesthetic
- minimal visual noise
- refined spacing rhythm
- premium SaaS feeling
- modern developer-tool aesthetic

Avoid:
- glassmorphism
- oversized gradients
- colorful backgrounds
- neumorphism
- overly playful UI
- thick shadows
- dribbble-style layouts
- AI-generic landing page style

Color system:
- background: #FAFAFA
- surface: #FFFFFF
- border: rgba(0,0,0,0.06)
- primary text: #18181B
- secondary text: #71717A

UI rules:
- radius: 10px-14px
- subtle hover states
- 1px borders for structure
- shadows should be barely visible
- spacing consistency is critical
- prioritize readability over decoration

Typography:
- use Inter or Geist
- medium font weights
- generous line-height
- clean documentation-style layout

Components should feel inspired by:
- Linear
- Vercel
- Stripe Press
- Notion
- Raycast

The interface should feel:
calm, premium, systematic, modern, quiet.
